Why Astra exists

An operating system
built for the web.

Astra is not a theme and not a demo. It’s a complete, functional desktop that runs entirely in your browser. Your files live in a real virtual file system backed by IndexedDB, your windows snap and tile, your browser has tabs, history and bookmarks — and nothing you do ever leaves your device unless you choose to open a web app.

01

No backend. No upload.

Every file is decoded on-device. Astra never uploads documents, images or media. Perfect for privacy-first workflows.

02

Offline-first PWA

Install as an app, boot with no network. Service worker caches the shell after first load — your OS is always with you.

03

Honest by design

When a browser boundary blocks something — camera, embed, headset — Astra says so. No fake numbers, no invented screenshots.

Why Astra

Fast, honest and
truly yours.

No frameworks, no build step, no backend. Just a folder you can open — or host on any static server. Every limitation is stated upfront.

Open Astra WebOS →

Nothing leaves your device

No file is ever uploaded. Office, media and images decode on-device. Test suite enforces zero fetch/XHR/WebSocket.

Lightweight & instant

Single-digit ms window open, virtualised grids, Web Worker image pipeline, 180-object-URL LRU — built for tabs, not servers.

Honest UI

Unsupported formats say “Format not supported by this browser.” Blocked embeds show a fallback — never a blank frame or invented art.

Web-native power

PWA manifest, service worker cache, Picture-in-Picture, EyeDropper & getDisplayMedia where the browser allows.

Customisable

9 themes, accent, glass blur, wallpapers, desk layouts, icon sizes, taskbar alignment & auto-hide — all persisted.

Built in the open

Plain HTML/CSS/JS, readable OOXML ZIP engine, hand-written parsers — no opaque SDKs, no hidden tracking.
